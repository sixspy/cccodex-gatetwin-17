# 闸对

中文名：**闸对** · 前缀 `gatetwin` · 端口 **6500 / 11500**

## 骨架

**刷卡点装载 → 同卡进站出站成对物化 → 缺腿/异向/超时旁路 → 行程账与刷卡点互证**

皮：地铁/公交闸机刷卡。去皮是 **OD 成对管道 + 开腿态 + 旁路 + 行程贯验**，不是票务售票 CRUD、不是乘车码业务页、不是日结封账。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6500
# 刷卡流 → 灌「成对样例」→ 看开腿账/行程账 → 再灌「缺腿超时样例」「出站孤儿样例」→ 行程贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 刷卡点 | 带卡号/站点/方向/事件时的进出闸事件 |
| 开腿账 | 已进站尚未出站的在途开腿 |
| 行程账 | 进站+出站成对后的正式行程 |
| 旁路匣 | 缺腿超时 / 出站孤儿 / 重复进站等 |
| 行程贯验 | 成对刷卡 ↔ 行程笔数 ↔ 旁路命运互证 |
| 日界裁决 | 只读裁决进站日/出站日/是否跨日/命运/valid（`GET /api/日界裁决`） |

## 日界架构（已落主链）

全局唯一口径：**日界强制切开禁跨**（站规 `日界架构`，另有 `站规时区`、`日界时刻`）。

- 日界是区间关系硬约束：进站运营日 ≠ 出站运营日时**禁止一笔成对**，日切只认**事件时**，禁止用处理日代替事件日。
- 跨日出站：进站腿置「日界强制结」并落旁路匣（原因 `日界禁跨`），出站按孤儿/新日规则旁路；批次末水位越过日界仍在途的开腿同样强制结。
- 行程账只收同日对，带 `进站日/出站日/是否跨日/日界架构` 字段；贯验追加「无跨日单笔、强制结↔旁路一一对应、禁止行程与旁路双落」校验。
- 成对写闸：开腿状态翻转带 `状态='在途'` 条件，任一旁路落定后再成对必然 0 行/抛错，从根上杜绝同一对双落。
- 对照另一可行架构「允许跨日成对」（本工程不采用，仅留 `日界.口径分叉` 自证）：两口径对「23:50 进、次日 00:10 出」是否一笔行程可区分。
- 夹具：`日界同日成对样例`（成对）、`日界跨日切开样例`（无跨日单笔）、`日界并发双落样例`（并发不得双落）；回归 `backend/tests/日界回归.py`。
